# cupertino_anchor_example

An interactive example demonstration and showcase app for the `cupertino_anchor` package.

## Features Demonstrated

- **Basic Dropdown**: Simple string-based Cupertino dropdown selection.
- **Top / Bottom Placement**: Automatic dynamic positioning testing both top edge and bottom edge placement modes.
- **Constrained Viewports**: Popover rendering with restricted screen height and smooth scrollbars.
- **Inside Scroll Views**: Tracking anchors inside `ListView` and `CustomScrollView`.
- **Keyboard Avoidance**: Interactive text field with keyboard insets testing.
- **Custom Generic Models**: Using `UserItem` model with custom `itemBuilder` and `selectedItemBuilder`.
- **Theming & Dark Mode**: Dynamic iOS light/dark mode switching and custom themes.

## Running the Example

```bash
cd example
flutter run
```
